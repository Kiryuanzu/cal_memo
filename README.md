# CALORIE MEMO BOOK

日々の摂取カロリーを簡単に記録することを目的に作られたRailsアプリケーションです。

筋トレ記録は `/daily_training_logs` の専用画面で入力・確認できます。食事画面の「筋トレ」から移動できます。
表示する日付を選び、家トレ／ジムの種目ボタンを押すだけで記録できます。
セット数・回数・重量（kg）・時間（秒）も記録する場合は「詳細を入力して記録（任意）」を開きます。
登録後は「この日の筋トレ」の各記録をクリックすると、詳細を追記・編集できます。空欄で保存すると、その項目を未入力に戻せます。
回数と時間は1セットあたりの値として記録します。同じ日に同じ種目を複数回記録することもできます。
日・週・月の部位別集計と、日付ごとの実施状況を一覧で確認できます。週は月曜〜日曜、月は暦月で集計します。
同じ日に同じ部位を複数種目・複数回記録しても、その部位の実施日数は1日です。筋トレ実施日数も日付の重複を除きます。
集計の一覧から日付を選ぶと、その日の入力・記録画面へ移動できます。記録がない日は「記録なし」と表示します。
選択日と前日の4部位を比較し、同じ部位を同じ区分で連日記録した場合は「家トレ 2日連続」「ジム 2日連続」と色で表示します。家トレとジムをまたぐ場合は連続扱いにしません。部位別の実施日数は引き続き両方をまとめて数えます。登録は制限しません。
週・月の先頭日も期間外の前日と比較します。比較用の前日は期間の実施日数には含みません。
通常の登録・詳細更新はTurbo Streamで必要な箇所だけ更新し、ページ先頭への移動を防ぎます。詳細編集は保存後も開いたままです。
詳細入力で記録日を別の日に変更した場合は、その日の入力欄へ移動します。
総セット数・重量推移は今後の対応です。

## DB更新・種目の登録

既存環境では次のコマンドを実行してください。

```bash
bin/rails db:migrate
bin/rails db:seed
```

seed は `db/seeds.rb` から食品用の `db/seeds/food_seeds.rb` と
筋トレ種目用の `db/seeds/training_exercise_seeds.rb` を読み込みます。
複数回実行しても同じマスタは重複しません。食品の追加・変更は `food_seeds.rb` で行います。
